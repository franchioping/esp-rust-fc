# ESP Rust FC - A WIP fully rust flight controller on ESP32

After the CanSat competition shitty flght controller code at [atlasat-2026/ESP32-CAN](https://github.com/atlasat-2026/ESP32-CAN) and [atlasat-2026/drone_controller](https://github.com/atlasat-2026/drone_controller)


I decided to remake the project, but properly, purely in rust. Not anywhere near finished. There are better options for ESP32 right now. If you are lost go look at [rtlopez/esp-fc](https://github.com/rtlopez/esp-fc)


This repo has a rapier3d **flight-sim**, **firmware** target for the esp32, **flight-control** library and a post flight **telemetry-viewer**, currently used only for the simulation.

There is no firmware code yet.
